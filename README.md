# Pomodoro Timer

A Pomodoro timer CLI written in C++. No external dependencies.

## Build

```bash
cmake -B build && cmake --build build
```

## Usage

```bash
./build/pomodoro
```

Running it opens an interactive menu:

```
=====================================
     POMODORO TIMER
=====================================

  Work Duration     : 25 minutes
  Short Break       : 5 minutes
  Long Break        : 15 minutes
  Number of Rounds  : 4 rounds

-----------------------------------
  1. Start Pomodoro
  2. Settings
  3. Exit
-----------------------------------
```

### Settings Menu

Change work duration, short break, long break, and number of rounds directly from the menu.

### Controls While the Timer Is Running

| Key | Action |
|---|---|
| `Space` | Run / Pause |
| `N` | Skip to next phase |
| `Q` | Exit to menu |
